# 💎 TON-кошелёк в Telegram

Некастодиальный кошелёк (Mini App): 24 слова генерируются на устройстве, шифруются PIN-кодом
(PBKDF2 + AES-256-GCM) и хранятся только там. Сервер и бот ключей не видят.

**Сеть: TON Mainnet (настоящие монеты).**

## Файлы
- `index.html` — кошелёк (Mini App), раздаётся через GitHub Pages
- `bot.py` — бот: кнопка «Открыть кошелёк» и кнопка в меню
- `requirements.txt`, `.env.example`

## Возможности
- Токены сети TON: USDT, NOT, DOGS и любые жетоны — баланс, цена, изменение за 24ч, отправка
- Общий баланс в долларах, вкладки «Активы» и «История»
- История с группировкой по дням: переводы, токены, обмены, NFT, детали и ссылка на Tonviewer
- NFT и подарки Telegram: сетка с картинками, свойства (модель, фон, узор), отправка другу, ссылки на Getgems и Tonviewer
- Несколько кошельков с переключением (как аккаунты), переименование, защита от дубликатов
- Адресная книга и недавние получатели, имена контактов в истории
- Безопасность: вход по Face ID / отпечатку (Telegram BiometricManager), автоблокировка, лимит попыток PIN с нарастающей паузой, защита от подмены адреса (address poisoning), скрытие баланса, смена PIN
- Создание (24 слова + проверка) и импорт кошелька, версии v4R2 и W5
- PIN-код для входа и для подписи каждой отправки
- Баланс, история с комментариями, QR-код для получения
- Отправка с комментарием, кнопка МАКС, ожидание подтверждения сети
- Показ секретной фразы по PIN, удаление кошелька

## Запуск бота
1. `pip install -r requirements.txt`
2. `.env.example` → `.env`: `BOT_TOKEN` и `WEBAPP_URL=https://timur850.github.io/ton-wallet/`
3. `python bot.py`

## Важно
- Первый раз проверь на маленькой сумме (0.1–0.5 TON).
- Токены, цены и история берутся из tonapi.io (ключ необязателен: `TONAPI_KEY`).
- Без API-ключа toncenter даёт 1 запрос/сек. Ключ бесплатно в @tonapibot → `TONCENTER_API_KEY` в index.html.
- Библиотеки TON грузятся с esm.sh (версии зафиксированы). Для большей безопасности их стоит собрать в бандл локально.
- Потеря 24 слов = потеря денег. Восстановить невозможно.
